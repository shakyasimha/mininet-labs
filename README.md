# Mininet Networking Lab

A collection of Mininet labs created to learn and experiment with computer networking concepts through hands-on practice.

## Repository Structure

```text
.
├── ipv4/
│   └── # IPv4 networking labs
├── ipv6/
│   └── # IPv6 networking labs
└── README.md
```

* **ipv4/** – Labs covering IPv4 networking concepts.
* **ipv6/** – Labs covering IPv6 networking concepts.

## Requirements

* Python 3
* Mininet
* Open vSwitch (OVS)
* Linux (Ubuntu recommended)

## Running a Lab

Navigate to a lab directory and run the Python script:

```bash
cd ipv4/<lab-directory>
sudo python3 <script>.py
```

or

```bash
cd ipv6/<lab-directory>
sudo python3 <script>.py
```

## Purpose

This repository is a personal learning resource for exploring networking concepts such as:

* Network topologies
* Host communication
* IPv4 and IPv6 networking
* Routing
* Mininet experimentation
